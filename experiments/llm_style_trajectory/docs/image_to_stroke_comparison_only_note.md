# 图像到笔画路线说明（当前主线线程仅作对比参考）

本说明只用于固定一个边界：

- 图像到笔画 / 书写行为恢复路线，当前**不是默认主线线程的推进方向**
- 它**不是当前默认 pipeline 的组成部分**
- 它当前只作为**后续结果对比、图像复核、论文讨论**的参考路线

## 当前默认主线线程中的含义

在当前默认主线线程里，这条路线最多只用于：

1. 与 A-route / B-route 结果做对比
2. 对图像结果进行人工复核或讨论
3. 在论文中作为相关方向、局限性或未来工作提及

因此，当前默认主线线程中：

- 不把它当成新的开发主线
- 不把它混入 A-route / B-route 的默认决策
- 不把它直接接入默认生成链路

## 这条说明不约束谁

这份说明**不约束未来单独开设的图像到笔画专责线程**。

如果未来明确开设一个独立线程，全权负责“图像到笔画 / 书写行为恢复”路线，那么：

- 那个线程可以把它作为自己的正式研究方向
- 那个线程可以独立设计方法、实验和论文叙事
- 不需要受本页“当前主线线程仅作对比参考”的限制

## 最重要的一句

这是一条“**当前主线线程的边界说明**”，不是“**永久禁止图像到笔画路线**”。
