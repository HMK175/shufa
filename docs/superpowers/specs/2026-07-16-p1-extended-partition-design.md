# P1-extended 字符划分设计

## 目标

为 P1-extended 生成可复现的训练、验证和测试清单。范围是 P1-core 的 9 位书法家候选与 ChineseStyle 的隶书、行楷候选；ChineseStyle 已由用户确认纳入论文实验，其许可状态仍记录为 `unverified`。

## 选定方案

采用字符级、分层的 80% / 10% / 10% 划分。每个 Unicode 字符只属于 train、validation、test 三者之一；繁体和简体按不同 Unicode 码位分别处理。以“该字符实际出现的外部风格数”作为分层依据，使用固定随机种子 `20260716` 在每层内打乱并分配。

这避免了同一个字同时出现在训练和评价中，也不会因为少量高覆盖字符而使验证、测试集偏向某一种风格。预演结果为 7,399 个字符：train 5,920、validation 738、test 741。各外部风格在验证和测试中均保留充足样本，最少的褚遂良分别为 97、98 张。

## 边界

- 当前外部字图候选为 11 种风格、39,741 张；P1-core 的另外 8 个 OFL 开源字体尚未渲染，不会伪装成现成图像。
- 划分产物同时生成 8 个开源字体在 7,399 个字符上的渲染计划（59,192 条）；后续渲染前仍须进行字体字符覆盖检查。
- 所有已在 P1-extended 中的外部风格均作为训练可见风格。此划分衡量的是**未见内容字、已见风格**的泛化，而不是未见风格泛化。
- 论文正式实验可使用 P1-extended；清单中必须保留 ChineseStyle 的 `unverified` 与 `user_confirmed_unverified_source` 来源状态。

## 产物与验收

构建器应生成：字符划分表、带 `character_split` 的外部样本表、开源字体渲染计划、风格统计表与汇总 JSON。验收时应验证字符集合无交集、所有 39,741 条样本均被纳入且与其字符划分一致、每个外部风格在三个集合中都有样本，且扩展样本均不具备论文资格。
